PLAYBACK GUIDE / 02

Cara mengambil audio stream

API menyediakan URL stream milik Aurelis, bukan URL Googlevideo permanen. Untuk YouTube, akses dipengaruhi pembatasan sumber, IP hosting, codec, dan dukungan HTTP Range.

01Temukan ID laguAmbil videoId dari /api/v1/search, atau gunakan ID demo seperti demo-aether.
02Resolve URL streamPanggil /api/v2/playback/:id; respons JSON menyediakan streamUrl dan probeUrl.
03Probe jika YouTubeUji probeUrl. HTTP 200 + ok:true berarti byte pertama tersedia; HTTP 424 berarti sumber gagal.
04Putar via audio HTML5Pasang streamUrl pada elemen <audio>; browser mengatur Range/seek otomatis.
INTERACTIVE PLAYGROUND

Uji stream langsung

Mulai dari demo yang terjamin tersedia di repo, atau tempel ID video YouTube.

HTTP
Masukkan ID lagu, lalu pilih “Dapatkan URL”.
GET /api/v2/playback/demo-aether

Catatan: probe sukses hanya memastikan respons awal, bukan jaminan bahwa seluruh lagu akan selesai diputar. Jangan menggunakan URL upstream hasil ekstraksi sebagai tautan permanen.

JAVASCRIPT · CONTOH IMPLEMENTASI
const track = await (await fetch('/api/v2/playback/demo-aether')).json();
const player = document.querySelector('audio');
player.src = track.streamUrl;
await player.play();
Streaming YouTube tidak selalu tersedia

GET /api/v2/audio/:videoId sudah mendukung relay Range ketika upstream mengizinkan. Jika YouTube meminta login, CAPTCHA, atau menolak IP server, API dapat mengembalikan HTTP 424. Aurelis tidak melewati DRM atau pemeriksaan anti-bot.

REFERENCE / 04

Batasan dan praktik baik

Gunakan URL relatif hasil resolver, periksa kode HTTP, batasi retry pada 429/424, dan gunakan Range hanya untuk seek yang didukung. Katalog demo menyediakan MP3 lokal; pencarian YouTube hanya menemukan metadata. Lirik tersedia berdasarkan lisensi dan provider; romanisasi kamus tidak selalu tepat untuk nama khusus. Riwayat serta playlist disimpan di browser kecuali fitur cloud diaktifkan.

REST API REFERENCE / VERSION 2.4

Build with music.

Temukan musik, atur rekomendasi, dan sinkronkan lirik. Satu API yang bisa kamu panggil dari website, bot, atau aplikasi Node.js.

BASE URLhttps://aurelis-symphony.go.altare.global
GET / POSTJSONTanpa kunci API untuk endpoint publik
Catatan pemutaran

API YouTube.js menyediakan hasil pencarian dan metadata, bukan jaminan audio. Streaming langsung melalui dua modul Node.js bersifat eksperimen, dapat dibatasi oleh YouTube, dan bukan integrasi playback yang disahkan YouTube.

GETTING STARTED

Contoh pertama

Permintaan ini mencari lagu berjudul Another Love. Gunakan query URL encoding dan periksa field tracks pada respons.

TERMINAL
curl -s 'https://aurelis-symphony.go.altare.global/api/v1/search?q=Another%20Love&provider=youtube&limit=5'
ENDPOINTS

Daftar endpoint

Coba permintaan GET langsung dari halaman ini. Endpoint POST ditampilkan dengan contoh body.

BATASAN

Yang perlu diketahui

Pencarian dan metadata bersumber dari YouTube (melalui modul tidak resmi). Lirik berasal dari LRCLIB atau lyrics.ovh jika tersedia. Terjemahan mengirimkan teks yang kamu pilih ke MyMemory. Playlist dan riwayat secara default disimpan di browser, bukan server. Beberapa API menerapkan rate limit dan dapat mengembalikan HTTP 429/503/424.
